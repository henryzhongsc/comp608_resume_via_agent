Why optimize a resume against a job description

  • A job description often describes the real role poorly.
  • HR teams and automated screening systems still rely on it heavily.
  • Screening is increasingly AI-powered, so the wording of a resume matters more every year.
  • A qualified candidate can be filtered out over wording rather than over ability.
  • Early-career applicants lose the most, because they have the least track record to compensate with.
1

Why use a coding agent

  • Commercial services such as Jobright already optimize a resume in one click.
  • One click produces one output, with no control over it and no room to refine it.
  • A coding agent can revise the same resume repeatedly until it is right.
  • The differences between versions show how you read each job, and they are worth keeping.
  • A git repo records every version, while a third-party service does not.
  • Most of you already pay for a coding plan.
2

You need a detailed experience bank first

  • An agent can only use experience that you have written down somewhere.
  • The pre-class assignment exists to build that written record.
  • Many resumes over-focus on the numbers and tech stack the writer wants to show off.
  • That focus loses the problem being solved, the scope that was owned, and what the work shows about the person.
  • Recording everything in detail lets the agent decide what belongs on the page.
3

How to run this

  • Clone the repo: github.com/henryzhongsc/comp608_resume_via_agent
  • Read the readme and inspect how the repo is organized.
  • Replace the example experiences and projects with your own.
  • Define the constants for each experience and project.
  • Replace the example job descriptions with postings you care about.
  • Inspect the /optimize-against-jd skill, then run it on a few of those postings.
  • Push the repo to GitHub, and set it to private.
4

Why a skill, and why constants

  • Targeting a resume is a repeated task, so the instructions belong in a reusable skill.
    • Every run is a chance to improve the instructions in that skill.
  • Constants declare what must appear no matter which job is targeted.
    • This repo declares them per experience and per project.
    • They can also decide which experiences and projects appear at all.
  • Several constant sets can be prepared and passed to the skill as an input.
