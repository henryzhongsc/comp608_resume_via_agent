# comp608_resume_via_agent

A workshop repo for COMP 608. You keep a detailed, unpolished record of what you
have actually done in `raw_info/`, and a coding agent turns that record into a
one-page resume aimed at a specific job description. The same source material
produces a different resume for each posting, and every version stays in the
repo, so what changed between them is visible.

The folder layout is documented in `CLAUDE.md`.

## Everything here is fictional

Fred Rice does not exist. The identity, the NBer internship, and the ClipPrompt
project are invented for demonstration purposes, along with every number in
them. The two Amazon job descriptions are real postings kept as examples.
Replace all of it with your own material.

## Disclaimer

This repo is here to help you experiment with using a coding agent for resume
work and to get you started. It is not the only way to arrive at a good resume,
and it is not a recommended standard. Take what is useful and ignore the rest.
